# DataForTrades — Homepage & Dataset Explorer redesign concept

A responsive React + Vite front-end concept for the DataForTrades homepage and dataset explorer.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Included interactions
- Search datasets by name, description, or category
- Filter the dataset list by category
- Clear filters and search
- Responsive mobile navigation

## Important concept notes
- This is a front-end mockup, not a production integration with DataForTrades.
- The headline collection figures (608,259 records, 44 datasets, 32 industries) are taken from the figures discussed for the current website.
- Dataset names, descriptions, row counts, update dates, and research pack examples in the table are illustrative placeholders. Replace them with verified live website data before presenting the concept as a faithful data replica.
